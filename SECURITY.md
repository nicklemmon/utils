# Security

## Report a vulnerability

Do not open a public issue for a security report.

Use GitHub private vulnerability reporting:

https://github.com/nicklemmon/utils/security/advisories/new

## Scope

This repository publishes TypeScript libraries. Reports that matter:

- Remote code execution through a published package
- Prototype pollution or injection in a public API
- Supply-chain issues in the build or publish path

## Supported versions

Only the latest published version of each `@nicklemmon/*` package is supported.
